zenoh-pico C examples in the browser

The upstream examples (examples/unix/c11), unmodified, built with Zig for wasm32-wasi with real threads. Each runs in its own Web Workers; stdout and stderr show up below. JavaScript API demo

Run

Start a router with zenohd -l ws/127.0.0.1:10000. Try z_sub, then z_pub; z_queryable, then z_get; z_pong, then z_ping (send q to z_pong to stop it).
